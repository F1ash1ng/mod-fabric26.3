# 机动装置开发日志

本文整合了 1.0.0 至 1.2.15 的项目计划推进记录、版本说明和已记录的验证结果。游戏版本目标为 Minecraft 26.3 / Fabric；截至 1.2.15，依赖基线为 Fabric Loader 0.19.5、Fabric API 0.162.0+26.3、Java 25。

## 2026-10-17 · 1.0.0：腰部装置与喷气突进

- 建立 Fabric 项目、Mod 元数据和开发客户端；实现不占原版护甲栏的独立腰部装备槽，以及中英文物品名。
- 完成默认 `V` 键的八方向喷气。方向在启动时锁定，行程 12 格，按距离曲线起步、巡航、减速；加入 7 秒冷却与装备状态下击杀清冷却。
- 接入已确认的 V2 腰部模型、方向喷口和物品图标；加入迅捷 I、强制疾跑、摔落保护 II 等效减伤和疾跑相关饥饿消耗减半。
- 添加只影响游戏画面边缘的径向动态模糊，并处理卸下、死亡、退出和切换世界时的视觉状态清理。
- 版本说明记录了 Gradle 构建和客户端 GameTest；当时完整 PCL 人工体验仍待验收。

## 2026-10-18 · 1.1.0–1.1.5：滑铲、跳跃衔接与玩家姿态

- 1.1.0 加入地面滑铲，默认左 `Ctrl`，沿锁定方向滑行；支持一格高通道、受限空间保持低姿态，以及喷气打断滑铲。
- 后续版本将滑铲行程调整为 5 格，并在末段开放跳跃打断窗口；服务端检查地面状态和站立空间，起跳保留滑行方向动量。
- 逐步修正第三人称姿态、身体朝向、手持物显示和滑铲状态同步，避免客户端提前结束时短暂显示原版游泳姿势。
- 后续维护接入盔甲姿态同步和 TaCZ 第三人称动作兼容；在代码中将兼容范围限制到相应动作状态。

## 2026-10-18–19 · 1.2.0–1.2.8：蹬墙跑与模型兼容

- 1.2.0 增加第三种机动效果 Wall Run：起跳后接近侧墙按空格进入，锁定脚部高度并沿墙移动；再次按空格朝准星方向蹬墙跳离。喷气、落地、死亡或卸下装置会结束墙跑并恢复重力。
- 1.2.1–1.2.3 迭代上墙条件、贴墙距离、视角转向边界和沿墙速度判定；禁止倒走上墙，避免镜头穿过正对墙面时左右倾斜跳变。
- 1.2.4 接入左右墙跑模型和分段骨骼动画，适配普通/纤细手臂、玩家皮肤、盔甲及腰部装置；同步观察者可见的姿态。
- 1.2.5 将墙跑速度调至疾跑速度的 175%，加入喷气冷却 HUD；满足条件时可从喷气转入墙跑。
- 1.2.6 修正左右模型选择、盔甲关节与皮肤外层贴合；退出动作或进入第一人称时恢复共享模型状态。
- 1.2.7–1.2.8 增加第三方 3D 皮肤层的墙跑期间回退兼容，并修正 AvatarRenderer 复用 PlayerModel 绘制盔甲造成的 UV、袖子和槽位网格问题。测试记录包含普通/纤细手臂、盔甲、皮肤外层及资源恢复检查。

## 2026-10-19 · 1.2.9–1.2.12：装备操作与 TaCZ 行为修正

- 1.2.9 增加手持右键及 Shift 点击快速装备；加入装备时的 TaCZ 枪械重量、移速和疾跑射击兼容。保留 TaCZ 自身弹药、装弹和命中判定，并让缺席的 TaCZ 不成为必需依赖。
- 1.2.10 修正墙跑、地面移动、喷气和滑铲期间的 TaCZ 腰射姿态输入；限定在相关动作中使用，滑铲已有表现保持不变。
- 1.2.11 修复服务端以移动速度判定疾跑射击时客户端表现与服务端拒绝不一致的问题；移动和各机动状态仍使用各自放行条件。
- 1.2.12 让装备强制疾跑只在有移动输入或执行机动动作时生效，停止移动后恢复站立持枪状态；服务端读取 26.3 客户端输入状态，而不再用惯性速度猜测按键。

## 2026-10-19 · 1.2.13–1.2.14：玩家设置、合成与连杀经验

- 1.2.13 加入 Shift 设置页；喷气、滑铲、Wall Run 可分别开关，TaCZ 功能覆盖默认关闭。设置同步至服务端并随玩家存档保存；关闭正在运行的技能时会结束技能。
- 1.2.14 加入固定形状的工作台配方，并将装备者亲自击杀的原版经验直接分配给玩家。击杀连杀提高经验倍率，连杀超时、死亡或卸下装置时清零；新增倒计时 HUD 和“经验用于经验修补”开关。

## 2026-10-19 · 1.2.15：专用服务器和双客户端联机

- 在独立 Minecraft 26.3 专用服务器上验证服务端装备/设置判定、客户端附件同步、喷气冷却与连杀状态、死亡重生、切换下界以及退出重登。
- 修复喷气、滑铲或墙跑期间跨维度后可能沿用旧维度状态的问题：技能记录启动维度，跨维度时清理姿态并恢复重力。
- 双客户端验证观察者能看到远端玩家的机动装置、喷气方向、滑铲姿态和墙跑姿态；覆盖八个喷气方向、滑铲朝向、左右墙跑和恢复站立。
- 保留物品规则开启时，死亡重生后装备及设置继续保留；关闭时装备按规则掉落。死亡会清除临时技能和连杀状态。
