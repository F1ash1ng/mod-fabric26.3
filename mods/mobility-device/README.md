# 机动装置（Mobility Device）1.2.15

为 Minecraft 26.3 Fabric 增加可装备的腰部机动装置，包含八向喷气突进、滑铲、蹬墙跑、装备被动效果和 TaCZ 可选兼容。

[返回 Minecraft 26.3 Fabric 模组合集](../../README.md) · [查看完整开发日志](DEVELOPMENT_LOG.md)

## 功能

- **腰部装备槽**：装置不占原版护甲栏；可通过创造模式、工作台配方或 `/give @s mobility_device:waist_jet` 获取。手持右键或 Shift 点击可快速装备。
- **八向喷气突进**：默认按 `V`，支持前后左右和斜向，按下时锁定方向；行程 12 格，冷却 7 秒。喷气时画面边缘有径向模糊，中心和 HUD 保持清晰。装备者击杀生物或玩家可重置冷却。
- **滑铲**：默认按左 `Ctrl`，在地面移动时触发，沿锁定方向滑行 5 格，可通过一格高通道；滑铲末段可跳起，喷气可以打断滑铲。
- **蹬墙跑（Wall Run）**：跳起后靠近侧墙按 `Space` 进入，沿墙移动或停留；再次按空格可蹬墙跳离。蹬墙跑速度为疾跑速度的 175%，镜头随墙面倾斜，喷气可打断墙跑。
- **装备被动**：穿戴时强制疾跑，获得相当于摔落保护 II 的摔落减伤，疾跑移动和疾跑跳跃产生的饥饿消耗减半；喷气和高处落地会触发迅捷 I。
- **击杀连杀经验**：亲自击杀会直接获得原版击杀经验并累加连杀加成；从 3 连杀起显示倒计时。可在设置中决定经验是否先参与经验修补。
- **机动设置**：在物品提示中按 Shift 打开设置页，可分别切换喷气、滑铲、蹬墙跑及 TaCZ 功能覆盖；设置会同步并随玩家存档保存。
- **TaCZ 可选兼容**：提供疾跑射击限制、枪械移动修正和持枪动画的兼容处理。TaCZ 不属于运行本 Mod 的必需依赖。

默认按键可在“选项 → 控制 → 按键绑定 → 机动装置”中修改。蹬墙跑可通过靠近墙面后按空格触发。合成配方为：

| 铜锭 | 红石粉 | 铜锭 |
| --- | --- | --- |
| 铁锭 | 钻石 | 铁锭 |
| 皮革 | 活塞 | 皮革 |

## 安装

- Minecraft **26.3**
- Fabric Loader **0.19.5 或更新版本**
- Fabric API **0.162.0+26.3**
- Java **25 或更新版本**

将 [`mobility-device-1.2.15.jar`](dist/mobility-device-1.2.15.jar) 和 Fabric API 放入 `mods` 文件夹。多人游戏中，服务端和每位玩家的客户端都需要安装本 Mod。JAR 的 SHA-256：`1C24E59AA08B659B4A8E09209BB956A8723D0B092DA59BAD67E61EA6C2FA7A1D`。

## 从源码构建

安装 Java 25 后，在此目录运行：

```powershell
.\gradlew.bat build
```

构建产物位于 `build/libs/`。项目也包含客户端 GameTest 和双客户端联机测试代码；详细开发与验证记录见[开发日志](DEVELOPMENT_LOG.md)。
