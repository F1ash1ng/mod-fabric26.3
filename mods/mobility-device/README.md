# 机动装置（Mobility Device）

为 Minecraft 26.3 Fabric 添加可装备的腰部喷气装置。穿戴后可沿八个方向进行长距离突进，并获得迅捷、摔落减伤和疾跑饥饿消耗减半等机动能力。装置使用独立腰部槽位，不占用原版护甲栏。

[返回 Minecraft 26.3 Fabric 模组合集](../../README.md)

## 功能

- **腰部装备槽**：在背包中装备“机动装置”，创造模式也可直接获取；不替换胸甲、护腿或靴子。
- **八方向突进**：默认按 `V` 启动，按键时读取视角与方向键，锁定本次移动方向；没有方向输入时向前突进。按键可在游戏控制选项中修改。
- **距离制动**：喷气行程为 12 格，起步迅速，中段保持速度，末段逐渐减速；升降与水平移动同步，障碍物会正常阻挡。
- **喷气视觉效果**：喷气时画面边缘出现径向动态模糊，中心和 HUD 保持清晰；效果随突进结束淡出。
- **冷却与击杀重置**：突进后冷却 7 秒；穿戴装置时亲自击杀活体会清空剩余冷却。
- **机动被动效果**：穿戴期间持续疾跑，获得相当于摔落保护 II 的摔落减伤，疾跑移动和疾跑跳跃产生的饥饿消耗减半。
- **迅捷 I**：喷气开始时，或穿戴状态下从超过 3.5 格高度落地时，获得 2.3 秒迅捷 I。
- **中英文本地化**：包含中文和英文物品名及按键名称。

当前没有合成配方。多人游戏中，服务端和游玩的客户端都需要安装本 Mod。

## 安装

- Minecraft **26.3**
- Fabric Loader **0.19.5 或更新版本**
- Fabric API **0.162.0+26.3**
- Java **25 或更新版本**

将 [`mobility-device-1.0.0.jar`](dist/mobility-device-1.0.0.jar) 和 Fabric API 放入实例的 `mods` 文件夹。SHA-256：`5484053BCBFBC783685E71F713F006443456D0DBD9E75AB494C8A48B2155F63F`。

装备后默认按 `V` 突进；也可输入 `/give @s mobility_device:waist_jet` 获取物品。背包中的腰部槽位位于角色装备栏旁边。

## 从源码构建

项目附带 Gradle Wrapper。安装 Java 25 后，在此目录运行：

```powershell
.\gradlew.bat build
```

构建产物位于 `build/libs/`。启动开发客户端：

```powershell
.\gradlew.bat runClient
```
