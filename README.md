# 智能合成器（Smart Crafter）

为 Minecraft 26.3 Fabric 添加可保存配方模板的合成器辅助模组。每台原版合成器都能单独保存九宫格模板；保存后，漏斗会按模板把材料送入对应槽位，减少自动合成装置中的错位和堵塞。

## 功能

- **配方搜索**：在合成器界面打开配方列表，按当前游戏语言的配方名称或配方 ID 搜索，并将配方布局载入模板编辑器。
- **独立模板**：每台合成器分别保存自己的九槽位模板，数据随方块实体保存。
- **手动编辑**：可从玩家背包选择物品作为模板预览，调整槽位内容；预览不会取走背包里的物品。
- **槽位开关**：关闭不需要的输入槽。漏斗只会向已启用且接受该物品的模板槽位输入；同种材料对应多个槽位时，优先填入空槽，再堆叠到匹配槽位。
- **重置模板**：点击“重置”只清除这台合成器保存的模组模板，不清空合成器库存，也不改动方块状态或红石状态。清除模板后，漏斗输入恢复原版行为。
- **中英界面**：编辑器与配方列表可切换中文和英文。
- **JEI 可选兼容**：安装 JEI 时可使用其合成配方输出预览；JEI 不是运行本模组的必需项。

## 游戏内使用

1. 放置原版合成器并打开它。在原版界面中点击 **“选择合成配方”**，或点击 **“编辑当前模板”** 修改已有模板。
2. 在配方列表中搜索并选择配方，进入模板编辑器。也可以从背包区选取物品来手动设置输入模板。
3. 将物品放入九宫格输入槽。左键可拿取或放入整组，右键可拿取一半或放入 1 个；**中键点击输入槽**可启用或关闭该槽位。
4. 点击 **“保存”** 应用模板。把漏斗对准合成器输入，材料就会进入启用且匹配的槽位。
5. 要取消自动筛选，在编辑器点击 **“重置”**。模板清除后，该合成器的漏斗输入按原版规则运行。

> 背包区只提供模板编辑用的物品预览，不会从玩家背包扣除物品。模板也不会替代合成器本身的库存或发射红石信号的规则。

## 安装

- Minecraft **26.3**
- Fabric Loader **0.19.5 或更新版本**
- Fabric API **0.162.0+26.3**
- Java **25 或更新版本**
- JEI **31.12.0.65**：可选

将[预编译 JAR](https://github.com/F1ash1ng/mod-fabric26.3/raw/refs/heads/main/dist/smart-crafter-1.0.0-reset-button.jar)和 Fabric API 放入实例的 `mods` 文件夹。该文件 SHA-256：`E913881AAD49DDA91C833043A657579A3A3DDE0624DFB71F3A560F24E19D7691`。使用整合包或启动器时，请确认它们与 Minecraft 26.3 兼容。

## 从源码构建

项目附带 Gradle Wrapper。安装 Java 25 后，在项目目录运行：

```powershell
.\gradlew.bat build
```

构建产物位于 `build/libs/`。启动开发客户端：

```powershell
.\gradlew.bat runClient
```
